Politique de confidentialité

Dernière mise à jour : 11 septembre 2026

DecodeMind (decodemind.dev) est un outil d'Archipel AI Ventures, entreprise établie à Lévis, au Québec. Il analyse du code source et explique ce qu'il trouve, en langage clair.

Votre code ne quitte jamais votre navigateur. Ce n'est pas une promesse commerciale, c'est la façon dont l'outil est construit : l'analyse tourne sur votre machine, dans l'onglet, et il n'y a pas de serveur à qui envoyer quoi que ce soit.

Ce que nous ne recueillons pas

Pas de compte. Pas de courriel. Pas de mot de passe. Pas de paiement. Pas de formulaire. Pas de statistiques de fréquentation, pas de mouchard, pas de témoin publicitaire. Nous n'avons aucune base de données vous concernant.

Votre code n'est ni téléversé, ni copié, ni lu par nous. Quand vous ouvrez un dossier, le navigateur donne à la page l'accès aux fichiers choisis, et vous seul décidez lesquels. L'analyse, les règles, la détection de failles et la traduction des messages se font entièrement dans l'onglet.

Ce qui reste sur votre appareil

  • Vos préférences (langue de l'interface, niveau de sévérité, taille du modèle) dans le stockage local du navigateur.
  • Le dossier analysé en dernier, pour vous le reproposer à la prochaine visite. C'est une permission que le navigateur retient, pas une copie de vos fichiers.
  • Les explications déjà traduites, gardées pour ne pas les recalculer. Elles sont rangées sous une empreinte du code, jamais sous le code lui-même.
  • Les copies de sauvegarde faites avant d'appliquer une correction : elles sont écrites dans votre propre dossier, dans .decodemind-backup.
  • Les fichiers de l'application, pour qu'elle fonctionne hors ligne.

Tout cela vit sur votre appareil. Vous l'effacez en vidant les données du site dans votre navigateur, et en supprimant le dossier de sauvegarde.

Les seules choses que votre navigateur va chercher ailleurs

Le bandeau d'annonces, en haut de la page, est chargé depuis GitHub Pages (GitHub, États-Unis) à chaque visite. GitHub voit donc votre adresse IP, comme pour n'importe quelle image hébergée ailleurs.

Le modèle d'intelligence artificielle, si vous demandez à l'outil de traduire les résultats en langage clair. Le modèle est alors téléchargé depuis Hugging Face (États-Unis) — plusieurs centaines de mégaoctets — puis gardé en cache par votre navigateur. Ce téléchargement ne se déclenche que si vous cliquez. Hugging Face voit votre adresse IP au moment du téléchargement. Ensuite, le modèle tourne sur votre machine : vos questions et votre code ne sortent pas.

Notre hébergeur, Cloudflare (États-Unis), sert les pages et voit votre adresse IP, comme tout hébergeur.

La base de vulnérabilités utilisée pour vérifier vos dépendances est incluse dans l'application : la consulter ne contacte personne.

Vos droits

Vous pouvez écrire à archipel.clients@outlook.com pour toute question, pour demander l'accès, la correction ou la suppression de renseignements vous concernant, et pour porter plainte auprès de la Commission d'accès à l'information du Québec.

Comme nous ne détenons aucune base de données d'utilisateurs, la réponse à une demande d'accès sera : nous n'avons rien à votre sujet. Ce que l'outil garde est sur votre appareil, et vous en disposez sans passer par nous.

Modifications
