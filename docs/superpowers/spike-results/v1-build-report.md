### Notes on manualChunks

`prettier` and `eslint` emit as empty stubs (0 bytes) because all their code is
consumed inside the self-contained Web Worker bundles (`eslint.worker-*.js`,
`prettier.worker-*.js`). The main thread has no direct imports of these modules,
so Rollup correctly places all their code in the workers. The stub chunks are
harmless — they satisfy the manualChunks declaration without duplicating code.

`@mlc-ai/web-llm`, `@ast-grep/wasm`, and `@astral-sh/ruff-wasm-web` are WASM-heavy
and intentionally excluded from bundling via `optimizeDeps.exclude`. They load
dynamically at runtime inside workers.
